# webgissiapcegah
WebGIS visualisasi hasil Kajian Risiko Bencana Kabupaten Barito Selatan
Didalam WebGIS ini menampilkan raster Bahaya, Kerentanan, Kapasitas, dan Risiko dari hasil penyusunan Kajian Risiko Bencana, dan informasi penting lainnya
Penggunaan WebGIS ini diperuntukkan bagi pihak terkait dan sebagai media edukasi dan pengenalan terkait Kajian Risiko Bencana
